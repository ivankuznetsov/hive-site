hive-bench v2

Which coding agent runs the hive pipeline best?

hive-bench replays real, completed hive tasks by driving the actual hive pipeline — plan → execute → open-pr → review — with each candidate's models, inside an isolated container. The final post-review diff is graded against the merged reference PR by two blind judges. It is the implementer-side sibling of agent-reviewer-eval.

Read the number honestly. The corpus is six Ruby/CLI tasks from one maintainer's repo, judge-scored (no curated test gates yet), mostly single judge seed. So this measures who runs the full hive workflow best on this corpus — not "best coding agent" in general. Judges that share a model family with a candidate never count toward that candidate's headline. See the methodology & limitations.

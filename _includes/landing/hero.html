Hive orchestrates your coding agents — Claude, Codex, Pi — to run work as a folder-as-agent pipeline: brainstorm, plan, execute, review, finalize, and ship the PR. Follow the queue and answer questions in the native local web UI, the TUI, or through an agent while tasks advance in parallel in the background. Idea → PR is its flagship coding workflow — and you can author your own for writing, research, triage, anything.

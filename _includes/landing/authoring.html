Custom workflows

Define stages in YAML

Use a YAML descriptor to set stage instructions, output files, and human decisions.

This minimal custom gate is separate from the Writing and Architecture Honeycombs above. Here, research.md feeds report.md. Approval completes the report; rejection returns the task to synthesis. Neither publishes or sends it.

Build a custom workflow →

research-report.ymlCustom example
id: research-report
stages:
  - name: research
    kind: agent
    state_file: research.md
    instruction: ./research-report/research.md
  - name: synthesis
    kind: agent
    state_file: report.md
    instruction: ./research-report/synthesis.md
  - name: approval
    kind: human
    state_file: approval.md
    input: report.md
    outcomes:
      approve: { complete: true, artifact: report.md }
      reject: { to: synthesis }

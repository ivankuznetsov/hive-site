A workflow you can read

Define the stages.
Keep the handoffs explicit.

A descriptor names the stages, their instructions, and their outputs. Agent stages do the work. Human stages hold a decision.

This custom Research example ends with an approved report. Rejecting it returns the same task to synthesis. Nothing is automatically published or sent.

research-report.ymlCustom example
id: research-report
stages:
  - name: research
    kind: agent
    state_file: research.md
    instruction: ./research-report/research.md
  - name: synthesis
    kind: agent
    state_file: report.md
    instruction: ./research-report/synthesis.md
  - name: approval
    kind: human
    state_file: approval.md
    input: report.md
    outcomes:
      approve: { complete: true, artifact: report.md }
      reject: { to: synthesis }

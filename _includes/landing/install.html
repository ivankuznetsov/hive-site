1. Install Hive

macOS · Homebrew
brew install ivankuznetsov/hive/hive
Arch Linux · AUR
yay -S hive-bin
Linux · glibc x86_64 / aarch64
tmpdir="$(mktemp -d)" && trap 'rm -rf "$tmpdir"' EXIT \
  && curl -fsSL https://raw.githubusercontent.com/ivankuznetsov/hive/v{{ site.hive_version }}/install.sh \
       -o "$tmpdir/hive-install.sh" \
  && bash "$tmpdir/hive-install.sh"

Current release: v{{ site.hive_version }}. Native install requires Ruby 3.4, Git, and your configured agent CLIs. Coding also uses authenticated gh. Full prerequisites →

2. Set up and open a project

hive setup
cd ~/Dev/your-project
hive init .
hive web status

Setup provisions the local services. Open the reported loopback URL, use hive tui, or drive tasks from your agent.

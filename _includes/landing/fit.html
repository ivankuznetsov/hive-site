Know the operating model

Hive is local-first workflow infrastructure, not a hosted control plane. Read the operator contract before enrolling a project or enabling its daemon.

A good fit if you…

  • Want long-running agent work to survive outside a chat session.
  • Prefer local, inspectable files for artifacts, decisions, and approvals.
  • Are comfortable running a local daemon and authenticated agent CLIs.

Probably not if you…

  • Need a hosted managed service. Hive is local-first, with a TUI, native web UI, CLI, and daemon on your machine.
  • Need every task to finish inside one synchronous chat session.
  • Cannot grant a configured agent access to the files and commands its stage requires.

Stage-level provider choice is explicit. Inspect the current Claude, Codex, Pi, and Grok profile contracts before selecting credentials and permissions.

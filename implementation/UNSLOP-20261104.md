## Five-line direction — recorded before product edits

1. **Product:** Hive runs local agent workflows with saved stage outputs,
   explicit human decisions, and recoverable attempts.
2. **Character:** Precise, warm, practical.
3. **World:** A document workbench: files move between named stages and remain
   available for the next agent or reviewer.
4. **Moments:** The existing factory carries an artifact; the inspector shows
   its saved inputs, approval decision, or retry state.
5. **Signature:** Honey-colored file handoffs, using the existing bee and
   shallow intake tray consistently.

## Nine passes — implementation decisions

1. **Spacing:** normalized HTML layout margins, padding, and gaps to the
   existing 4px rhythm; retained 1–2px optical/accessibility offsets and the
   SVG's geometric coordinates. Capability articles use a column layout so
   their small proof rows align despite differing paragraph wraps. No boxes
   were added.
2. **Color:** kept the warm neutral ramps and honey accent. No new colors,
   gradients, shadows, or highlights; the active artifact/control remains the
   bright content. Verify text contrast in the rendered checks below.
3. **Icons:** retained the existing Hive mark, bee, and semantic arrows/status
   indicator. No emoji decoration, icon library, brand-logo invention, or new
   ornament was needed. Removed decorative capability numbering with its copy.
4. **Copy:** replaced slogans and antithesis throughout visible sections and
   all three demo narratives with named stages, files, outcomes, and actions.
   Kept human decision/retry limitations, supported-agent setup requirements,
   illustrative vs historical labels, proof limitations, and hosted waitlist
   status. Removed unsupported “Built by Hive itself” credit.
5. **Type:** kept Space Grotesk and existing system/mono partners. Loosened
   heading tracking, used tabular stage indices, raised 10px labels/code to
   at least 11px, and raised agent setup notes to 12px. Mobile hero is 36–44px;
   desktop remains capped at 72px. No added weight or uppercase labels.
6. **Layout:** section order and the 9/6/3 workflow renderer are unchanged.
   Removed duplicate eyebrow/slogan layers above the demo and the redundant
   hero note. Hero has Get started and Read the docs; GitHub remains in primary
   navigation, mobile menu, and footer. The supported-agent grid keeps its
   user-approved composition. No new cards, pills, or layout system.
7. **Details:** removed pill treatment from inline artifact filenames in the
   capability prose. Preserved restrained radii, focus rings, selected states,
   and actual Built-in / Custom example / Opt-in labels. Shortened the narrow
   manual control to “Next stage” without changing its transition behavior.
8. **Visuals:** retained the original factory, shallow intake tray, bee, and
   artifact forms. Reviewed the skill's hero reference for restraint only;
   did not borrow its subject/layout. No image prompt or generation: the
   approved SVG already explains this product.
9. **Motion:** no change. The animation is finite, explicitly started, gated by
   visibility, and explains handoffs. Keyboard, reduced-motion, and no-JS
   behavior remain intact. No entrance animation, looping decoration, or
   animated layout property was added.
